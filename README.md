# LA Referencia OCLC Harvester

Modified OCLC Harvester2 library (2006) adapted for LA Referencia platform.

## 🎯 Functionality

Low-level OAI-PMH 2.0 protocol implementation providing XML parsing, record extraction, and resumption token handling. Used internally by lareferencia-core-lib.
